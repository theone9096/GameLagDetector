LagDoctor 游戏卡顿检测工具
===========================
【怎么用】(打包成 exe 之后)
 1. 双击 LagDoctor.exe（Windows 如弹出管理员提示请点"是"，这样游戏里的 F8 热键才生效）
 2. 点【开始监控】
 3. 切到游戏正常玩，工具会自动识别游戏
 4. 觉得卡的时候按 F8
 5. 玩完回来点【结束并诊断】，查看是 硬件 / 网络 / 游戏优化 哪类问题
 结果文件保存在 用户目录\LagDoctor\ 下

【怎么得到 exe】三选一
 A. 有 Python 的 Windows 电脑：先把压缩包【完整解压】到一个文件夹，再双击 build_windows.bat（不要在压缩包里直接运行），
    等 1-3 分钟，成功后会自动打开 dist 文件夹，里面就是 LagDoctor.exe；失败时窗口会停住显示原因
 B. 没有 Python：把本文件夹上传到 GitHub 仓库 -> Actions -> Build LagDoctor -> Run workflow，
    完成后在页面底部 Artifacts 下载 Windows / Mac 版
 C. Mac：终端运行 ./build_mac.sh

【说明】
 - 打好的 exe 可拷给任何电脑用，不需要装 Python
 - exe 只能在打包它的系统上运行(Windows 的 exe 不能在 Mac 上用)
 - GPU 指标仅支持 N 卡；杀毒软件偶尔会误报 PyInstaller 程序，选择信任即可

【判断加速器有没有用】(v2 新增)
 工具会自动从游戏进程的网络连接里找到游戏服务器，并做逐跳链路监测(类似 mtr)，
 报告里的"网络专项诊断 & 加速器建议"会告诉你问题出在哪一段，以及加速器预期效果：
   本地WiFi/路由器 -> 无效 | 运营商接入网 -> 低 | 骨干网/跨网 -> 高 | 服务器机房侧 -> 低
 想用数据验证(最可靠)：
   1. 先【不开加速器】玩一会，结束并诊断
   2. 再【开着加速器】玩一会：开始前勾选"本次已开启加速器"，结束并诊断
   3. 点【对比加速器效果】，依次选这两次的结果文件夹(在 用户目录\LagDoctor\ 下)
   命令行: python lagdoctor.py --compare 未开目录 开启目录
 注意:
   - 加速器请用"路由/TUN/全局"模式；若只加速游戏进程，本工具的探测流量走不到加速器，看不出效果
   - 两次测试时长、时间段尽量相近(网络状况会随时间变化)
   - 部分 UDP 游戏服务器屏蔽 ping，可手动填写能响应的 IP:端口
   - 逐跳监测依赖系统自带的 tracert/traceroute，被拦截时只做端到端判断
